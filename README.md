# Peer-to-Peer Item Borrowing & Rental Backend

A RESTful backend system for short-term item rentals, built for ITEC 116 Systems Integration and Architecture 2.

## Tech Stack
- NestJS
- TypeORM
- MySQL
- JWT Authentication & Bcrypt

## How to Run Locally
1. Start MySQL in XAMPP and create a database named `p2p_rental_db`.
2. Run `npm install` to install dependencies.
3. Configure your `.env` file with your MySQL credentials.
4. Run `npm run start:dev` to start the server on `http://localhost:3000/api/v1`.
